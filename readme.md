# My Very Excellent Video Graphics Rendering System
(or MVEVGRS if you don't have the time)

MVEVGRS is a software renderer written in Rust.

It's designed to be very user extendable with support for user written update function, vertex transformations and pixel coloring. For an explination on how to use the renderer, please consult the examples programs and <nobr>./src/renderer/user_stage/mod.rs .</nobr> Also say hi to Trig the triangle. ![Trig, the MVEVGRS mascot](./icon.png)
